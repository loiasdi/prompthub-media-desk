# PromptHub MediaDesk · 同步到飞书

采用飞书企业自建应用的服务端 API，不依赖飞书 CLI。工作台单向同步到飞书，Obsidian 继续保存本地稿件和素材；飞书中的修改不会自动回写。

## 首次创建

1. 打开 https://open.feishu.cn/app ，创建企业自建应用，开启机器人能力。凭证页提供 App ID 和 App Secret。
2. 在权限管理中申请云文档读写、云空间读写和多维表格读写。常用权限为 `docx:document`、`drive:drive` 和 `bitable:app`；以各接口文档列出的可用权限为准。应用发布后，企业管理员按租户要求批准权限。
3. 在飞书云空间新建专用文件夹，给应用编辑权限。可将应用机器人加入群，再将群添加为文件夹协作者；应用有 API 权限不代表自动获得所有文件的访问权。
4. 新建一个专用多维表格，并给应用编辑权限。使用普通云空间文件夹和 Base 链接，不使用知识库节点链接。
5. 打开工作台任意稿件，点「同步到飞书」，展开首次配置。填写 App ID、App Secret、文件夹 Token、多维表格 App Token 和 Table ID。
6. 保存并「检查连接」，然后「读取飞书并预览同步」。

链接标识：`https://你的租户.feishu.cn/drive/folder/<folderToken>` 中的标识是文件夹 Token；`https://你的租户.feishu.cn/base/<appToken>?table=<tableId>` 中分别是 App Token 和 Table ID。填写标识本身，不填写整条链接。

表格使用主字段显示标题，详细描述和话题只保存在稿件文档中。首次同步会按顺序补齐制作状态、稿件文档、素材链接、最近同步时间、工作台ID等多行文本字段；工作台ID最后创建。如有同名字段却不是多行文本，预览会中止。现有其他字段不会被删除。

## 使用

先保存稿件与提示词，再点同步按钮读取飞书内容。窗口提供已有文档全文、表格字段和目标文件夹的当前层文件列表。本次素材显示新增上传、重新上传或无需上传。图片默认勾选，视频与音频手动选择。确认后才写入飞书。任务期间显示当前文件和进度；服务端继续处理，请等待结束。

每篇稿件建立一个文件夹、一份云文档和一条表格记录。文档包括标题、描述、话题、正文、完整视频提示词、封面各比例提示词和素材链接。图片、视频、音频的原文件按稿件归档到云空间文件夹，表格和文档中保留访问链接。图片同时以图片块直接展示在对应稿件文档中，标明封面／参考图片及文件名，封面比例可从封面设计关联读取；视频和音频保留访问链接。本版不使用多维表格附件字段。文档图片上限为 20 MB。文档文件名和文件夹名以首次创建时为准，最新标题同步到正文和表格。

按实时计算的 SHA-256 对文件内容去重，不凭文件名和修改时间判断。云空间文件和文档内图片使用不同的飞书 token，首次插图需额外调用文档素材上传接口；之后文字更新或图片改名会保留原图片块，不再次上传。图片内容变化时先插入新版，再移除旧图片块，云空间旧文件仍保留。只改文字或文件名不会重传视频；同名文件内容变化会上传新文件。工作台记录的已上传文件若已从飞书文件夹删除，将重新上传。本版只复用同稿件、同目标配置下由工作台上传并记录的文件；以前手动上传的内容可浏览，但不自动关联或去重。文件列表仅当前层与本稿件文件夹，不递归浏览整个云空间。

同步前、执行前均检查本地与飞书快照。发现飞书手动编辑时，要求重新预览并勾选覆盖确认，且只改工作台管理的文档内容和工作台管理的字段；其他字段保留。文档写入使用版本约束，更新先追加完整新版再移除旧块，失败时可能短暂保留两版，重试可修复。

每个完成上传的文件立即保存 token、指纹和链接，之后失败不会让已完成文件重传。大文件按官方分片接口上传，单文件上限 250 MB；未完成的那个文件重试时从头上传，暂不支持跨重启分片续传。文件夹和文档创建成功后立即记录其 ID；网络在创建成功但响应丢失时可能留下未关联对象，遇到此类情况先检查飞书目标文件夹，避免重复创建。表格创建使用稳定工作台ID检索和幂等请求标识，后续更新同一行。

本地删除不会删除飞书记录和文件，新版视频不会自动删除旧视频。同步记录请勿手动删除，否则失去去重和归属信息。任务执行失败后先重新预览，再重试。

## 本机配置与接口

App Secret 和同步 manifest 放在 `$DSH_HOME/media-desk-feishu/`（默认 `~/.dsh/media-desk-feishu/`），文件权限 600，不写入 Obsidian。只有是否已保存密钥返回前端。租户 token 只保存在内存中。数据目录及飞书目标配置共同决定同步记录，切换目标不会沿用其他表格的 ID。

接口前缀 `/media-desk/feishu/`：GET `config`、GET `job?id=...`，POST `config`、`test`、`preview`、`sync`。预览有效期十分钟，确认同步后生成可轮询任务。预览不创建飞书文件、字段、文档或记录；读取飞书表格筛选结果会调用官方 POST search 接口。服务重启后任务状态不恢复，但已落盘文件记录仍可复用。正式环境沿用 Host 认证，预览仅监听本机；写操作拒绝跨站请求。
