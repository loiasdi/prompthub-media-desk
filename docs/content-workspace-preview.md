# PromptHub MediaDesk · 内容制作页面预览

内容详情按稿件 → 视频提示词分阶段展示，并提供封面设计、素材与发布标签。改稿页只显示标题和正文，创作助手按需展开；稿子确定后直接进入视频提示词，整理片段和参考素材。底部「下一步」仅切换制作阶段，不代表锁定稿件或调用模型；后端的一键成稿目前仍沿用原有生成逻辑。素材文件、文件夹、片段草稿、制作设置、发布文案及选材已接入本地持久化，刷新页面或重启服务后可恢复。

## 启动

```bash
npm install
npm run preview
```

默认监听本机 `http://127.0.0.1:4311`，未配置共享目录时使用独立数据，不调用模型或发布平台。可通过 `npm run preview -- 4312` 换端口。

预览数据保存在系统临时目录下的 `dsh-media-desk-preview`，具体路径在启动时输出。它会跨服务重启保留，但仍可能被系统清理；需要长期保留时，使用 `MEDIA_DESK_PREVIEW_DIR=/你的目录 npm run preview` 指定独立目录。正式 DSH 环境默认使用 `$DSH_HOME/media-desk`（默认 `~/.dsh/media-desk`）。配置共享目录后，默认预览和正式环境都使用共享目录；`MEDIA_DESK_PREVIEW_DIR` 仍可指定独立预览目录。

| 页面 | 地址 |
| --- | --- |
| 内容列表 | http://127.0.0.1:4311/ |
| 稿件 | http://127.0.0.1:4311/?tab=article |
| 视频提示词 | http://127.0.0.1:4311/?tab=prompts |
| 封面设计 | http://127.0.0.1:4311/?tab=cover |
| 素材文件夹 | http://127.0.0.1:4311/?tab=assets |
| 发布 | http://127.0.0.1:4311/?tab=publish |
| 深色英文窄屏 | http://127.0.0.1:4311/?tab=publish&theme=dark&lang=en&width=390 |

预览服务按请求重新构建前端；修改代码后刷新页面即可看到结果。`width` 参数用于模拟内容容器宽度，不能代替手机浏览器的触摸和媒体兼容性测试。

## 可操作的页面

- 内容卡片：素材数量、选定成片提示，以及提示词／素材／发布快捷入口。
- 视频提示词：以完整原文保存「全局视频参数＋分段多镜头」；支持整份粘贴、编辑、自动保存与手动保存；按 `【第1段 - 13.3秒】` 识别目录，支持小数秒；整份复制、TXT 原文导出、全局参数＋当前段复制。旧版片段通过显式转换生成文档，原片段保留。参考文件在素材页管理并在视频工具中单独上传。
- 封面设计：每篇内容独立保存封面提示词，支持原文编辑、自动保存、手动保存、复制与 TXT 导出；封面图片在素材页管理。
- 素材：多文件及文件夹选择、拖入文件、上传进度与逐文件结果、类型筛选、搜索、网格／列表切换、新建及重命名子文件夹、修改文件名／用途／位置、媒体预览和下载、移到回收站及恢复。
- 发布：选择视频或图文、编辑平台文案、选择发布视频及封面、按选择顺序选图、预览和基础准备检查；手动发布文案复制及发布清单导出。
- 定时发布：预览执行方式、时间和时区，尚不创建可执行任务。

导入文件流式写入本地存储，元数据保存到对应内容的工作区中。编辑自动保存，页面显示待保存、保存中、已保存及失败状态。多个窗口发生保存冲突时，不会覆盖另一窗口的结果；可先导出本窗口草稿，再重新加载工作区。

重新加载期间若有新输入，本次加载会中止并保留草稿，可导出后再次加载。文件入库成功后，即使随后保存制作设置失败，该文件仍显示为已导入；使用「重试保存」重试草稿即可。

未手动修改的发布标题、正文和平台随内容更新；手改字段会保留，来源变化时显示提示，可用「同步变化字段」更新这些字段。素材身份按文件地址区分，重画的新文件不会继承旧文件的移除记录、名称或发布选择。已登记在工作区中的旧版生成文件会保留，原有发布选材仍指向旧版，可手动换成新版。

视频提示词文档使用独立的 `promptText` 原文存储，最多 500000 字符；未知格式同样可保存，目录识别不会重写原文。空文档与尚未转换的旧版数据区分存储；导出不插入标题、配置或附件说明。参考文件仍需在视频工具中单独上传。

AI 生成和自动发布按钮暂时禁用。目标模型选项用于预览配置和导出标记，尚未实现模型专用提示词转换。发布清单只包含文案与选定文件名；批量打包和正式发布版本将在后续实现。

已有稿件生成、保存和排期功能在正式 DSH 环境继续使用原接口。独立预览服务只提供示例内容、基础编辑和撤销，不模拟真实模型调用成功。

## 导入与回收站规则

- 支持 JPEG、PNG、WebP、GIF；MP4、WebM、MOV；MP3、WAV、M4A、AAC、OGG。单文件上限为 250 MB，单篇最多登记 2000 个素材、200 个文件夹。
- 同一篇内容按队列依次导入，单个文件失败不影响其他文件。「取消剩余导入」停止等待中的文件，正在处理的文件会等待服务器确认。失败文件可重新选择导入。
- 文件夹按媒体类型区分，支持一层自定义文件夹。导入多层目录时，将相对目录合并为文件夹名称，例如 `参考/场景`；不创建多层目录树。
- 本机有 `ffprobe` 时，读取媒体时长及图片／视频尺寸，并校验可读性；有 `ffmpeg` 时为视频生成缩略图。缺少工具时仍保存文件，详情中显示元信息或缩略图不可用的原因。签名不符、超限、探测失败或保存失败的文件不登记入库，并清理本次产生的文件。
- 移到回收站会取消对应的发布选材和参考关联。恢复时保留名称、用途、文件夹，不自动重新选为发布素材。
- 当前回收站不提供永久删除或自动清空，文件仍占用磁盘空间。导入中断留下的临时 `.part` 文件在超过 24 小时后由后续导入清理；不自动扫描删除正式文件。
- 图片、音频及视频可在素材页预览和下载；播放能力取决于浏览器支持的编码。文件接口支持 Range 和 HEAD 请求。

## 数据与接口

内容的 `workspace` 字段保存 schema 版本、修订号、素材登记、文件夹、回收站、片段、制作设置及发布草稿。导入和制作生成的文件实体存放于数据目录的 `内容/<内容ID>/素材/`，与稿件和提示词在同一篇内容目录；页面中的逻辑文件夹仍用于分类，不改变物理路径。未归属内容的通用上传和模型测试文件仍在 `files/`。文件身份及引用只在所属内容范围内校验，不允许客户端登记任意本地文件地址。

| 接口（前缀 `/media-desk/`） | 用途 |
| --- | --- |
| `GET workspace?id=...` | 读取内容工作区 |
| `POST workspace/save` | 保存草稿，JSON 包含 `id`、`revision`、`draft` |
| `POST content-assets/import?id=...&revision=...&name=...` | 请求体为原始媒体流，可附加 `folder` 和 `relativePath` |
| `POST content-assets/trash`、`content-assets/restore` | JSON 包含 `id`、`revision`、`assetId` |

成功写入后递增 `revision`，旧修订号返回 HTTP 409。Host 进程之间通过存储锁串行执行状态变更。正式入口继续使用现有 DSH 认证和跨站写入检查。

## 封面 Skill 工作流

封面页内置 `src/skills/atutun-xhs-cover.md`（来自用户提供的 Skill）。单页选择参考图、填写封面文字和选填的补充要求；风格、用色、人物分类和比例收在“更多设置”。新建任务默认生成 3:4、16:9、4:3 三种比例，已有任务保留原比例。用户本次要求优先于 Skill 默认规则。不要求手动分类参考图，由模型判断用途；仅使用参考图已有的人物，不凭空添加人物。

正式 DSH 通过当前文字模型执行 Skill，参考图通过宿主 attachments 服务作为真实图片传入；支持标题候选和按比例生成提示词。独立预览不连接模型，可编辑和保存所有字段、复制设计任务到外部 Skill/ImageGen 对话。生成提示词不会直接在服务端覆盖草稿，返回后由保存队列统一落库。

HTTP 生图：无参考图使用 `/images/generations`，有参考图使用 `/images/edits` 多文件上传；模型须支持目标精确尺寸（3:4 为 1152×1536，16:9 为 1536×864，4:3 为 1536×1152）并返回 `b64_json`。不支持时显示错误，不静默忽略参考图。当前 DSH 工具适配只支持纯文字生图且不保证目标比例，带参考图时拒绝调用并提示使用 HTTP 或外部 ImageGen。生成图作为候选保存，用户需检查实际尺寸、文字、人物后再选为发布封面；不会宣称自动完成视觉审核。

封面需求与三个版本保存在 `workspace.coverDesign`，每版独立存提示词及生成图 ID；重试生成保留旧图片。原来的 `coverPromptText` 保留，可手动导入任一比例。接口 `cover/titles`、`cover/prompts`、`cover/image` 需当前工作区修订号，避免并发覆盖。模型输出、参考图传入及图片上传测试使用模拟服务；未调用付费模型进行真实出图验证。

简化后的预览使用方式：在封面页上传并勾选参考图，填写封面文字，可选补充“文字居中”等要求，然后点“复制到 Skill 对话”，到原有对话附图继续生成。连接模型后显示“生成封面提示词”，每版可继续生成图片；结果与已有提示词编辑收在展开区。

## 稿件基础信息

稿件页的标题、描述、话题分别保存在 `production.title`、`production.description` 和 `production.topics`。编辑后离开输入框即保存；描述和话题可以清空。新成稿的模型规划会同时生成描述和话题，历史稿件可手动补全。没有独立描述字段的旧稿件仍沿用原来的发布正文兜底，避免改变已有发布文案。

发布页默认读取稿件标题、描述、话题；未手改字段随稿件更新，手改字段保留并显示来源变化提示。旧版没有话题编辑标记但已有发布话题的内容按手动编辑保留。封面页“使用当前内容标题”读取稿件标题，Skill 请求同时带上描述和话题作为上下文，不覆盖已填写的封面文字。

## 共享 Obsidian 目录

在 `$DSH_HOME/media-desk-storage.json`（默认 `~/.dsh/media-desk-storage.json`）配置：

```json
{
  "root": "/绝对路径/Obsidian Vault/自媒体工作台",
  "markdown": true
}
```

重启服务后生效。`MEDIA_DESK_DATA_DIR` 可覆盖数据目录，`MEDIA_DESK_MARKDOWN=1` 可启用 Markdown 输出。配置只切换位置，不自动迁移或合并旧目录；切换前应停止服务，将原目录的 `state.json` 和 `files/` 复制到新位置，并保留备份。正式环境的模型设置 `settings.json` 如需迁移应单独处理，避免将密钥同步到笔记库。

`state.json` 是工作台的主数据，`内容/<内容ID>/素材/` 保存各篇导入与生成的素材，`files/` 兼容旧版文件及未归属内容的上传。`内容索引.md` 按标题提供稿件与素材入口。每次保存后自动将标题、描述、话题、稿件、视频提示词和封面提示词输出至 `内容/<内容ID>/` 下的 Markdown 文件，可通过 Obsidian 搜索标题。素材笔记链接到同目录树中的文件。

Markdown 目前是单向输出，Obsidian 的编辑不会自动回写工作台。检测到手动编辑时保留原笔记，将工作台的新版本另存为 `*.工作台更新-<版本摘要>.md`，避免覆盖。工作台中删除内容不会自动删除已有笔记。请勿手动编辑 `state.json` 或 `.markdown-manifest.json`。

### 旧版混放素材归档

停止服务后，可在项目根目录执行 `node --input-type=module -e "import { Store } from './src/store.js'; import { migrateContentAssets } from './src/migrate-content-assets.js'; console.log(await migrateContentAssets(new Store()))"`。迁移按现有内容引用复制、逐文件核对后移除旧位置的文件；多个稿件使用同一文件时，各自保留副本。不改写素材 ID、选材和旧 URL，原引用仍可访问。无归属文件留在原处。迁移前应保留数据备份。

## 飞书同步

每篇内容顶部提供「同步到飞书」，支持首次配置、检查连接、查看远端内容、文件指纹去重、同步计划确认、进度与重试。预览环境也支持真实飞书 API，同步需显式确认。创建自建应用、权限和使用说明见[飞书同步](feishu-sync.md)。
