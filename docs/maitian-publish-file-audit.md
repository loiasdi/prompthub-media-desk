## 字段和文件对应

| 工作台数据 | 导出字段 / 文件 | 检查结果 |
| --- | --- | --- |
| 工程标识 | `version: 1`、`id`、`name` | 与原版工程读取一致；导出 ID 区分不同快照 |

| 视频号短标题、正文 | `platforms.channels.shortTitle` / `body` | 独立短标题 6–16 字、正文 0–1000 字；不把普通标题误当短标题 |
| 话题 | `topics: ["工程校验", "验证样例"]` | 去掉开头 `#`，按空白、英文或中文逗号拆分并去重 |
| 小红书竖封面 | `covers["3x4"]` 和 `platforms.xhs.covers` | 声明和引用一致；实际文件 300×400 |
| 视频号两张封面 | `covers["3x4"]`、`covers["4x3"]` 和平台 `covers` 数组 | 实际文件分别 300×400、400×300；检查真实尺寸，不信任登记标签 |
| 未选自定义封面 | 根 `covers: {}`、平台 `covers: []` | 原版允许，使用平台默认封面；不会引用不存在的文件 |
| 立即填写 | 不写 `schedule` | 没有空字符串、null 或旧预约时间残留 |
| 北京时间预约 | `schedule` 为带 UTC 时区的 ISO 时间 | 原版 `bjTime()` 转回的北京时间与输入一致 |
| 视频时长 | `durationSec` | 来自实际媒体探测，测试成片读回 4 秒 |
| 工作台来源摘要 | 额外的 `media-desk-manifest.json` | 原版扫描忽略该附加文件，不影响工程识别 |

`requiredTags: []` 不强加作者账号标签。正文按原文保存，保留换行；不会自动删除上游不允许的文字或截断超长文案。导出前调用原版 `validate()`，原版的字数、引流内容和模型名称等限制也会阻止导出。
